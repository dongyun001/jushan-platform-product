## 二、Docker 容器服务

所有容器通过 `/opt/jushan/docker-compose.prod.yml` + `/opt/jushan/.env.production` 管理。

```bash
cd /opt/jushan
docker compose -f docker-compose.prod.yml --env-file .env.production up -d
```

| 容器名 | 镜像 | 端口映射 | 用途 |
|--------|------|----------|------|
| `jushan-mysql` | `mysql:8.4` | `127.0.0.1:3306→3306` | 主数据库 |
| `jushan-redis` | `redis:7-alpine` | 内网 `6379` | 缓存/会话/WebSocket |
| `jushan-rabbitmq` | `rabbitmq:3.12-management` | 内网 `5672` | 消息队列 |
| `jushan-emqx` | `emqx/emqx:5.8.5` | `0.0.0.0:1883`, `127.0.0.1:18083` | MQTT Broker |
| `jushan-backend` | `jushan-platform:latest` | 内网 `8080` | Spring Boot 后端（Webhook 接收地址 http://127.0.0.1/api/v1/device-webhook/events 经 nginx） |
| `jushan-nginx` | `nginx:alpine` | `0.0.0.0:80` | 反向代理 + 前端静态资源 |

| 端口 | 协议 | 用途 | 授权来源 |
|------|------|------|----------|
| 80 | TCP | Nginx（前端 + API） | `0.0.0.0/0` |

## 十、常用运维命令

### 查看所有容器状态
```bash
cd /opt/jushan && docker compose -f docker-compose.prod.yml ps
```

### 重启后端
```bash
cd /opt/jushan
# 1. 构建新 JAR：mvn clean package -pl parking-boot -am -Dmaven.test.skip=true
# 2. 上传 parking-boot/target/parking-boot-*.jar 到 /opt/jushan/parking-boot/target/
# 3. 重建并重启
docker compose -f docker-compose.prod.yml --env-file .env.production build backend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d backend
```

### 重启 device-access

> 推荐使用 `restart-device-access.sh`，它会自动从 `.env.production` 加载 `WEBHOOK_URL` 等环境变量。

```bash
/opt/jushan/restart-device-access.sh
```

### 查看后端日志
```bash
docker logs -f --tail 100 jushan-backend
```

### 查看 device-access 日志
```bash
tail -f /opt/jushan/logs/device-access.log
```

### 连接 MySQL
```bash
docker exec -it jushan-mysql mysql -u jushan -p
```

### 查看 EMQX 客户端
```bash
docker exec jushan-emqx emqx ctl clients list
```

### 部署前端
```bash
# 1. 本地构建：cd frontend && npx vite build
# 2. 上传：rsync -avz --delete dist/ root@<SERVER_IP>:/opt/jushan/frontend/dist/
```

### 芊熠 Q3 图片链路（v1.6）

芊熠 Q3 相机（固件 20.0.471）默认 `alonepush=0`，图片通过 MQTT `result` 消息的 `full_pic`/`plate_pic` 字段以 base64 编码直传，由 device-access `PlateRecognizedEventDispatcher` 解码落盘。

若后续启用 `alonepush=1`，相机将走 HTTP `/images/upload` 独立上传路径。

### 臻识 C5 图片链路

臻识 C5 通过 FTP 主动上传图片到 `/opt/jushan/data/device-images/`，或通过 MQTT `snapshot` 命令主动抓拍。事件携带的 OSS 签名 URL 由 `RemoteImageDownloader` 在事件到达时立即转存本地。

### 重启 FTP
```bash
systemctl restart vsftpd
```

## 十一、启动顺序

1. Docker 基础服务（自动启动）：
   ```bash
   cd /opt/jushan
   docker compose -f docker-compose.prod.yml --env-file .env.production up -d mysql redis rabbitmq emqx
   ```

2. 后端（依赖 MySQL/Redis/RabbitMQ 健康检查通过后自动启动）：
   ```bash
   docker compose -f docker-compose.prod.yml --env-file .env.production up -d backend nginx
   ```

3. device-access（宿主机进程，需后端 + EMQX 就绪后）：
   ```bash
   nohup /opt/jushan/start-da.sh > /tmp/start-da.out 2>&1 &
   ```
