## 三、Webhook 协议

### 签名方式

```java
// HMAC-SHA256
String sign = HmacUtils.hmacSha256Hex(webhookSecret, requestBody);
// 验证: 请求头 X-Signature == sign
```

### URL

```
POST /api/v1/device-webhook/events
Headers:
  X-Signature: <HMAC-SHA256签名>
  X-Device-SN: <设备SN>
  X-Event-Type: recognition / heartbeat / status
Body: JSON (原始设备事件)
```

### 事件映射

`DeviceWebhookController.mapToEvent()` 将 DA 推送的原始事件映射为 `DeviceWebhookEvent` 对象，含：
- 车牌号（大写）
- 车牌颜色
- 车辆类型（相机识别结果，后续被系统判定引擎覆盖）
- 车身颜色（bodyColor，V20260906015）
- 车标（carLogo，V20260906015）
- 方向（entry/exit）
- 图片 URL

## 四、识别联动模板

设备表（device）中的 6 个模板字段：

| 字段 | 场景 | 默认值 |
|---|---|---|
| `voice_entry_welcome_template` | 入场语音欢迎 | `入口欢迎{type}车牌{plate}` |
| `voice_exit_welcome_template` | 出场语音 | `出口再见{type}车牌{plate}` |
| `voice_forbidden_template` | 禁止入场语音 | `禁止入场{type}车牌{plate}` |
| `display_entry_welcome_template` | 入场显示屏 | 同上 |
| `display_exit_welcome_template` | 出场显示屏 | 同上 |
| `display_forbidden_template` | 禁止入场显示屏 | 同上 |

占位符 `{plate}` → 车牌号，`{type}` → 车辆类型中文标签。

前端编辑时自动隐藏前缀 `{plate},{type},`，预览时拼接示例值。

## 六、device-access 数据库

device-access 有自己的独立数据库 `device_access`，与 parking-boot 的 `jushan_platform` 在同一 MySQL 实例上（仅库名不同），通过独立 Flyway 迁移管理。主要表：

| 表名 | 说明 |
|---|---|
| `t_device_product` | 设备产品型号（品牌、型号名、device_type、protocol、capabilities JSON） |
| `t_device` | 设备实例（SN、product_id、状态） |
| `t_event_outbox` | 事件发件箱（识别事件持久化 + 重试，Webhook 推送前的中间队列） |

> 数据库连接信息见 DA 的 `application-prod.yml`，用户名/密码与 parking-boot 的 MySQL 相同（`jushan` / `<见 .env.production>`）。
