# 03 — 开发环境搭建

## 一、前置依赖

| 工具 | 版本要求 | 说明 |
|---|---|---|
| JDK | 21（推荐 Zulu 21.38.21） | `JAVA_HOME` 需正确配置 |
| Maven | 3.9+ | 项目编译 |
| Node.js | 20+ | 前端构建 |
| pnpm 或 npm | 最新 | 前端包管理（推荐 pnpm） |
| Docker + Docker Compose | 最新 | 本地运行 MySQL/Redis/RabbitMQ/EMQX |
| Git | 最新 | 版本控制 |

## 二、克隆项目

```bash
git clone git@gitee.com:zeng-bohan-66/jushan-platform-product.git
cd jushan-platform-product
git checkout develop
```

## 三、本地中间件启动

```bash
# 启动 MySQL + Redis + RabbitMQ
docker run -d --name jushan-mysql-dev \
  -e MYSQL_ROOT_PASSWORD=<本地开发密码> \
  -e MYSQL_DATABASE=jushan_platform \
  -e MYSQL_USER=jushan \
  -e MYSQL_PASSWORD=<本地开发密码> \
  -p 3306:3306 \
  mysql:8.4 --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

docker run -d --name jushan-redis-dev \
  -p 6379:6379 \
  redis:7-alpine --requirepass <本地开发密码>

docker run -d --name jushan-rabbitmq-dev \
  -e RABBITMQ_DEFAULT_USER=admin \
  -e RABBITMQ_DEFAULT_PASS=<本地开发密码> \
  -p 5672:5672 -p 15672:15672 \
  rabbitmq:3.12-management
```

## 四、后端启动

### IDE 配置（IntelliJ IDEA）

1. 打开项目根目录
2. 等待 Maven 依赖下载完成
3. **VM Options**（Run Configuration）：
   ```
   -Dspring.profiles.active=dev
   -Ddb.url=jdbc:mysql://localhost:3306/jushan_platform?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
   -Ddb.username=jushan
   -Ddb.password=<本地开发密码>
   -Dredis.host=localhost
   -Dredis.password=<本地开发密码>
   -Drabbitmq.host=localhost
   -Drabbitmq.username=admin
   -Drabbitmq.password=<本地开发密码>
   ```
4. 主类：`com.jushan.platform.ParkingBootApplication`
5. 模块：选择 `parking-boot`

### Maven 命令行启动

```bash
# 完整编译
mvn clean package -pl parking-boot -am -Dmaven.test.skip=true

# 仅编译 parking-system（快速检查编译错误）
mvn compile -pl parking-system
```

## 五、前端启动

```bash
cd frontend

# 安装依赖
pnpm install

# 开发模式（代理到本地后端 8080）
pnpm dev

# 生产构建
pnpm build
```

开发模式下 Vite 默认 `http://localhost:5173`，API 自动代理到 `http://localhost:8080`。

## 六、数据库初始化

Flyway 在应用启动时自动执行迁移，无需手动建表。所有迁移文件位于：
```
parking-boot/src/main/resources/db/migration/
```

版本号从 `V20260710001` 到 `V20260906018`，共 **118 个**迁移文件。

### 手动测试数据库

```bash
mysql -u jushan -p<本地开发密码> jushan_platform --default-character-set=utf8mb4
```

### 查看迁移

```sql
SELECT version, description, installed_on, success
FROM flyway_schema_history ORDER BY installed_on;
```

## 七、Device Access 启动

device-access 为独立 Maven 项目，需单独编译启动。它有自己的 MySQL 数据库 `device_access`（默认端口 3307），也有独立的 Flyway 迁移：

```bash
cd device-access
mvn clean package -Dmaven.test.skip=true

# 启动（需要本地 EMQX，MQTT broker URL 通过环境变量或 application-local.yml 配置）
java -jar device-access-starter/target/device-access-starter-*.jar \
  --spring.profiles.active=local
```

**本地调试前置条件**：
1. MySQL 中需存在 `device_access` 数据库
2. EMQX broker 需可访问（本地 `tcp://localhost:1883` 或远程 `tcp://<MQTT_BROKER_IP>:1883`）
3. 本地需启动 parking-boot（DA 通过 Webhook 推送事件到 parking-boot）

## 十、常见本地开发问题

**Q: 启动 parking-boot 报 "Access denied for user"**
→ 检查本地 MySQL 是否已创建 `jushan_platform` 库，用户名密码是否正确。

**Q: Flyway 报 checksum mismatch**
→ 参照 [部署运维手册 第八节](./02-部署运维手册.md#八flyway-迁移修复) 处理。

**Q: 前端代理不到后端**
→ 检查 `vite.config.ts` 中 proxy 配置的 target 是否为 `http://localhost:8080`。

**Q: device-access 启动后 Webhook 推送失败**
→ 检查 `application.yml` 中 `device-access.webhook.url` 是否指向 parking-boot 地址（本地默认 `http://localhost:8080/api/v1/device-webhook/events`）。
